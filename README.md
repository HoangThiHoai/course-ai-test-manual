# Course AI Test Manual

Repo lưu trữ tài liệu phục vụ khóa học/thực hành kiểm thử phần mềm có hỗ trợ AI, sử dụng hệ thống demo **Perfex CRM** (https://crm.anhtester.com) làm đối tượng kiểm thử.

## Cấu trúc thư mục

```
course-ai-test-manual/
├── docs/               # Tài liệu đặc tả yêu cầu (SRS) cho từng module
│   └── SRS_Login.md    # SRS module Đăng nhập (Login)
└── TC/                 # Test case cho từng module
    └── TC.rtf
```

- **docs/** – Chứa các tài liệu Software Requirements Specification (SRS), mô tả yêu cầu chức năng, phi chức năng, quy tắc nghiệp vụ và kịch bản kiểm thử tham khảo cho từng module của hệ thống.
- **TC/** – Chứa các file test case chi tiết được xây dựng dựa trên SRS tương ứng.

## Hệ thống đối tượng kiểm thử

- **Tên hệ thống:** Perfex CRM – Anh Tester Demo
- **URL:** https://crm.anhtester.com

## Mục đích sử dụng

- Soạn thảo SRS cho từng module dựa trên khảo sát thực tế hệ thống.
- Xây dựng test case dựa trên SRS.
- Thực hành quy trình kiểm thử phần mềm có sự hỗ trợ của AI (sinh SRS, sinh test case, review...).
